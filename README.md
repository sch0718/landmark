<p align="center"><b>평소에 모아 두고, 여행 때 꺼내 쓰는 장소 보관함</b><br>
<a href="https://landmark.sch0718.dev">landmark.sch0718.dev</a> · 설치·회원가입 없이 휴대폰과 PC 브라우저에서</p>

가 보고 싶은 맛집·카페·명소를 그때그때 모아 두세요. 라벨과 이모지로 정리해 두면 여행을 갈 때 일정으로 바로 꺼내 쓸 수 있고, 친구와 만날 곳을 정하거나 링크 하나로 나눌 수도 있습니다.

## 이런 걸 할 수 있어요

|                  |                                                                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 📍 **모으기**    | 네이버 지도 링크를 붙여 넣거나, 네이버 공유 폴더를 통째로 가져오거나, 지도에 핀을 찍어 장소를 담습니다. 라벨(색·이모지)로 정리하고 메모를 남깁니다. |
| 🔎 **찾기**      | 라벨·지역·이름으로 거르고 지도에서 봅니다. 내 근처에 저장해 둔 곳, 영업시간·휴무도 알려 줍니다. 다녀온 곳에는 한 줄 평을 남깁니다.                  |
| 🧳 **여행 계획** | 모아 둔 장소를 Day별로 배치하면 이동 시간과 도착 시각을 계산합니다. 여행 당일에는 오늘 일정과 다음 장소 길찾기를 크게 보여 줍니다.                  |
| 🤝 **약속 잡기** | 모두의 출발지에서 대중교통·자동차로 공평한 번화가 역을 찾고, 후보 링크로 받은 친구 답장을 자동 집계해 확정합니다.                                   |
| 🔗 **나누기**    | 고른 장소나 여행 일정을 링크나 HTML 파일 하나로 보냅니다. 받은 사람은 설치 없이 보고, `Landmark에 담기`로 자기 보관함에 넣습니다.                   |
| 💾 **백업**      | 보관함 전체를 파일 하나로 받아 두고, 다른 기기나 새 브라우저에서 되살립니다.                                                                        |

## 시작하기

1. 휴대폰이나 PC 브라우저로 **[landmark.sch0718.dev](https://landmark.sch0718.dev)** 를 엽니다. 휴대폰에서는 브라우저의 `홈 화면에 추가`로 앱처럼 쓸 수 있습니다.
2. 가운데 **＋** 를 눌러 첫 장소를 담습니다. 네이버 지도 앱에서 장소를 공유해 링크를 복사한 뒤 붙여 넣으면 이름·주소·위치가 채워집니다.
3. 라벨을 붙여 정리해 두고, 여행을 갈 때는 **여행** 탭에서, 친구를 만날 때는 **약속** 탭에서 꺼내 씁니다.

## 간단한 사용법

- **장소 담기** — ＋ → 링크 붙여넣기·네이버 폴더·지도에 핀 중 하나를 고르고, 미리보기에서 라벨을 골라 담습니다. → [장소 추가](docs/help/add.md)
- **정리하고 찾기** — 보관함 위쪽 칩으로 라벨·지역을 고르고, 장소를 눌러 메모·라벨·다녀옴을 적습니다. → [보관함](docs/help/library.md) · [장소 상세](docs/help/place.md) · [라벨 관리](docs/help/labels.md)
- **여행 짜기** — 여행 탭에서 새 여행을 만들고, 후보에 장소를 담아 Day로 옮기면 이동 시간이 붙습니다. → [여행](docs/help/trips.md)
- **약속 잡기** — 약속 탭에서 새 약속을 만들고 참석자 출발지를 넣은 뒤 `중간 지점 찾기`. 후보 링크를 보내면 친구의 좋아요·출발지가 자동 저장되고, 열린 약속 화면에서 10초마다 집계해 확정합니다. → [약속](docs/help/meetings.md)
- **나누기** — 보관함에서 장소를 고르고 공유 창에서 `링크 복사`. → [공유](docs/help/share.md)

## 내 데이터는 어디에 있나요?

- 로그인 없이 쓰며, 보관함은 **지금 쓰는 기기의 브라우저에** 저장됩니다. 새 약속은 `후보 링크 보내기`를 누르면 서버에 사본을 올려 친구 답장을 모읍니다.
- 서버 사본은 약속 일시와 마지막 변경 중 늦은 쪽에서 30일 뒤 만료돼 정리됩니다. 주최자가 먼저 지울 수도 있고, 보관함의 약속과 이미 받은 답장은 남습니다.
- 장소·일정을 `카카오톡`으로 보내면 짧은 링크를 위해 **암호화한 사본**을 서버에 둡니다(장소 30일, 일정은 여행 끝 7일 뒤·최대 180일). 푸는 키는 링크에만 있어 서버는 내용을 읽을 수 없고, 링크를 받은 사람은 누구나 볼 수 있습니다. **설정 › 보낸 짧은 링크**에서 먼저 지울 수 있습니다. `링크 복사`로 보낸 링크는 서버에 저장하지 않습니다.
- 브라우저 데이터를 지우면 함께 사라지므로 가끔 **설정 › 백업**에서 백업 파일을 받아 두세요. 7일 넘게 백업하지 않으면 보관함 위에 알림이 뜹니다.
- 다른 기기로 옮길 때는 백업 파일을 그 기기에서 되살립니다. 약속의 주최자 연결 정보는 백업에 들어가지 않으므로, 다른 기기에서 약속을 고치려면 약속 메뉴의 `다른 기기에서 열기`로 주최자 링크를 보내세요.
- 링크나 파일로 보낸 장소(와 함께 보내기로 고른 메모)는 그것을 받은 누구나 볼 수 있습니다.
