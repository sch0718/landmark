# 랜드마크 아이콘

[비교 페이지](preview.html)는 파일 하나만 열어도 동작합니다. 세 시안을 밝고 어두운 바탕에서 각각 512·180·32·16px 실제 크기로 비교할 수 있습니다.

| 시안                  | 모양                                       | 특징                                           |
| --------------------- | ------------------------------------------ | ---------------------------------------------- |
| A · 핀 안의 산 (추천) | 라임 바탕, 검정 지도 핀, 산 모양의 빈 공간 | 저장한 장소와 여행지를 함께 나타냅니다.        |
| B · 여행지의 문       | 검정 바탕, 살구색 아치문                   | 명소의 입구와 새로운 여행의 시작을 나타냅니다. |
| C · 해와 산길         | 하늘색 바탕, 검정 산과 해, 비워 낸 산길    | 풍경을 찾아 떠나는 여행을 나타냅니다.          |

**A를 추천합니다.** 16px에서도 두꺼운 핀의 윤곽이 남고, 산이 ‘명소’라는 뜻을 보탭니다. pastel 테마의 라임(`#D9F99D`)과 검정(`#18181B`)을 그대로 사용해 앱과 잘 어울립니다. 글자·가는 선·그라데이션 없이 사각형 하나와 경로 두 개로 구성했습니다.

세 시안의 핵심 도형은 가운데 80% 안에 있습니다. A의 핀은 중앙에서 반지름 204.8px인 maskable 안전 원 안에도 들어갑니다. 일반 아이콘은 둥근 사각형이며, maskable PNG는 운영체제가 모서리를 자를 수 있도록 같은 라임색으로 모서리까지 꽉 채웁니다. apple-touch-icon도 불투명한 바탕을 채워 운영체제가 모서리를 처리하게 합니다.

## 다시 만들기

```sh
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
yarn build:icons
```

`scripts/build-icons.mjs`는 `icon-a.svg`를 원본으로 파비콘을 복사하고 PNG 4개를 렌더링합니다. 이 작업 환경에서 Chromium 실행이 차단되어, 저장소에 이미 설치된 `wrangler → miniflare → sharp@0.35.4`의 SVG 렌더러를 사용합니다. 네트워크·추가 의존성·개발 서버가 필요 없습니다. 크기와 PNG 압축 옵션을 고정하므로 같은 렌더러 버전에서 같은 바이트를 얻을 수 있습니다. 의존성 업데이트로 렌더러가 바뀌면 가장자리와 압축 결과에 차이가 날 수 있습니다.

SVG를 바꾸면 비교 페이지의 인라인 SVG와 `src/components/brand/AppLogo.tsx`도 함께 맞춥니다. 생성한 PNG는 저장소에 포함하고, 앱 빌드에서는 아이콘을 다시 만들지 않습니다.

매니페스트의 바탕색과 테마 색은 pastel 밝은 모드의 `bg.base`(`#FAFAF7`)입니다. HTML의 모드별 테마 색은 밝은 모드 `#FAFAF7`, 어두운 모드 `#111113`으로 맞췄습니다.
