# 다듬기 3: 디자인 QA·접근성 (하위 프로젝트 D3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 키보드만으로 쓸 수 있고, 여섯 테마 모두 WCAG AA 대비를 지키고, 입력칸이 한 모양이며, 화면 구조(본문·제목·탭 제목)가 분명한 앱으로 다듬는다.

**Architecture:** 대부분 테마(`src/theme/*`)와 공용 조각(`src/components/*`)의 변경이다. 포커스 표시·입력칸 테두리·대화상자 제목은 테마 재정의로 한곳에서, 입력칸 모양은 `fieldSx` 한 함수로, 색은 토큰으로 바꾼다. 화면별 변경은 제목·포커스 이동·배치 기본값처럼 좁게 한다. 묶음마다 커밋(작업)을 나눠 하나씩 되돌릴 수 있게 한다.

**Tech Stack:** React 19, MUI 7(테마 `components` 재정의), Jotai, @dnd-kit(accessibility 옵션), sonner, Vitest 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-design-qa-design.md`

## Global Constraints

- 셸은 Node 24: `export PATH="/opt/homebrew/opt/node@24/bin:$PATH"`(git 훅에도 필요). 주석·UI 문구는 한국어, 주변 코드 관례를 따른다.
- 커밋 메시지 끝: 세션이 알려 주는 Co-Authored-By 줄. **작업 하나 = 커밋 하나**(스펙 §8 — 묶음별로 되돌릴 수 있게). 리뷰 수정은 그 작업의 커밋에 이어 붙이지 말고 별도 커밋이어도 된다.
- 파일에 U+2028/U+2029 원문자 금지. 커밋 전 `grep -rnP '[\x{2028}\x{2029}]' src functions tests` 출력 없음.
- 새 문구는 이것뿐: `본문으로 바로 가기`, `알림`, 탭 제목 `<화면> · 랜드마크`(`보관함`·`지도`·`<장소 이름>`·`라벨 관리`·`설정`·`여행`·`<여행 제목>`·`옛 여행 가져오기`, 못 찾으면 `랜드마크`), 화면에 안 보이는 `h1` `보관함`·`지도`, 끌기 안내 `스페이스나 엔터로 들고, 방향키로 옮긴 뒤, 스페이스나 엔터로 놓아요. Esc를 누르면 취소돼요.`, `들었어요: <이름>`, `옮길 자리: <N>번째`, `놓았어요: <이름>`, `옮기기를 취소했어요`. 그 밖의 문구는 바꾸지 않는다.
- 대비 기준(여섯 테마 pastel·paper·night × light·dark): 보조 글자(`text.secondary`·`text.muted`)와 강조색 글자는 `bg`·`bg.surface`·`bg.raised` 위 **4.5:1**, 포커스 바깥선과 입력칸 테두리(`border.strong`)는 **3:1**. 이미 기준을 넘는 토큰은 바꾸지 않고, 바꾸는 값은 같은 색상(hue)에서 밝기만.
- 포커스 표시: `outline: 2px solid var(--tm-accent); outline-offset: 2px`, `:focus-visible`에서만.
- 입력칸: 한 줄 높이 44px, 여러 줄 기본 96px(메모 132px 유지), 글자 16px, 여백 `px: 1.25`, 배경 `bg.raised`, 테두리 `--tm-border-strong`(잘못된 값이면 `error`), 모서리 `--tm-radius-md`, 비활성 `opacity: 0.5`.
- 여행 계획 후보 칸: 화면 폭 **1100px 미만**이면 접힌 상태로 시작.
- 저장 형식·키(`schemaVersion` 2, `tripmap:library:v2`, `tripmap:prefs`, `tripmap:routes:v1`)와 공유 형식을 바꾸지 않는다.
- E2E는 `E2E_PORT=5175`(5173은 다른 프로젝트의 개발 서버 — 절대 끄지 않는다, 5174는 지도 미리보기 서버). `pkill` 금지.

## Review Focus

1. **포커스 바깥선이 마우스 클릭에도 보이거나, 둥근 칩·목록 행에서 잘림** → `:focus-visible`만, `overflow: hidden` 부모가 있는 자리는 `outline-offset`을 안쪽으로. Task 2 테스트(포커스 방식별)와 Task 6 캡처로 확인.
2. **추가 칸이 열릴 때 포커스를 옮기다 지도·목록 스크롤이 튐** → `focus({ preventScroll: true })`. Task 2.
3. **`Esc`가 칸 안의 다른 Esc 동작(라벨 고르기 메뉴·대화상자)까지 칸을 닫음** → 열린 메뉴·대화상자가 먼저 받고(이벤트가 거기서 멈춤), 칸은 그 밖에서 온 Esc만. Task 2 테스트.
4. **색 토큰을 바꾸며 다른 짝(흰 글자 on 강조색 버튼, 칩 배경 위 글자)의 대비가 떨어짐** → 대비 테스트에 그 짝도 넣는다. Task 3.
5. **`fieldSx`로 바꾸며 자리마다 있던 배치 값(`flex`, `width`, 오류 테두리)이 사라짐** → 기존 화면 테스트 전부 통과 + Task 6 전후 캡처. Task 4.
