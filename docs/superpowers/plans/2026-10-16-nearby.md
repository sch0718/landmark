# 내 근처 저장 장소 (묶음 F4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 보관함 정렬 `가까운 순`과 지도 `내 위치 보기`로, 저장한 장소를 내 위치에서 가까운 순·반경 안으로 보고 지도에 내 위치 점을 그린다. 위치는 누를 때만 묻고 어디에도 저장하지 않는다.

**Architecture:** Effect 서비스 `Geolocation`(약속 C2: `current`·`watch`)이 브라우저 위치 API를 감싼다. 내 위치·근처 모드는 메모리 Jotai atom(`src/stores/my-location.ts`)에만 두고, 보관함 목록과 지도가 같은 훅(`useNearby`)으로 같은 장소 집합을 본다. 지도는 `MapAdapter.setMyLocation`(네이버: Marker+Circle, 가짜: DOM 요소)으로 점을 그리고, `MapView`가 오른쪽 위 단추 기둥(`＋/−` 아래 `내 위치 보기`)을 맡는다.

**Tech Stack:** TypeScript 6, React 19, MUI 7, Jotai, Effect 4.0.2(`Context.Service`, `Effect.callback`, `Effect.result`), Naver Maps JS v3, Vitest 5(jsdom, `@effect/vitest`), Playwright(`permissions`·`geolocation`).

**Spec:** `docs/superpowers/specs/2026-10-16-nearby-design.md`

- 위치 요청은 사용자가 `가까운 순`·`다시 찾기`/`다시 시도`·`내 위치 보기`를 누를 때만. 앱 시작·새로고침·반경 바꾸기에는 요청하지 않는다.

- 값: 반경 `[500, 1000, 3000, 5000, 10_000, null]`(null = 전체), 기본 3000. 정확도 경고 1000m 초과. 반경 경계는 포함(≤). 동점은 이름(`localeCompare(…, 'ko')`) → id.
- 거리 글자: <1,000m는 10m 단위 반올림·최소 `10m`, 1~10km는 소수 한 자리 `2.4km`, ≥10km는 정수 `14km`. 반올림이 다음 단계에 닿으면 다음 단계(995 → `1.0km`, 9,960 → `10km`).
- 고정 문구(스펙 §4·§6):
  - 정렬 메뉴 `가까운 순`. 근처 줄: `내 위치를 찾는 중…` / `내 위치를 찾는 중… 실내에서는 오래 걸릴 수 있어요` / `내 위치에서 <반경> 안 · <N>곳 · <HH:mm> 기준` / `내 위치에서 가까운 순 · <N>곳 · <HH:mm> 기준` / `위치 오차가 커요(약 <거리>)` / `직선거리` / 버튼 `다시 찾기`·`다시 시도`·`가까운 순 끄기`(× 버튼 이름) / 칩 묶음 `반경`, 칩 `500m` `1km` `3km` `5km` `10km` `전체`.
  - 빈 상태 `반경 <반경> 안에 저장한 곳이 없어요` + `반경 넓히기`. 행 거리 앞의 숨은 말 `내 위치에서 `.
  - 지도: 버튼 `내 위치 보기` / 찾는 중 `내 위치를 찾는 중`, 성공 알림 `내 위치를 지도에 표시했어요`, 좁은 화면 칩 `내 근처 <반경>`(전체면 `내 근처`).
  - 오류: `denied` `위치 권한이 꺼져 있어요. 브라우저 설정에서 이 사이트의 위치 권한을 켜 주세요` / `unavailable` `지금은 위치를 알 수 없어요. 잠시 뒤 다시 해 주세요` / `timeout` `위치를 찾는 데 시간이 너무 오래 걸려요. 다시 해 주세요` / `unsupported` `이 브라우저에서는 위치를 쓸 수 없어요`.
