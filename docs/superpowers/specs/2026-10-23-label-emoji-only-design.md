# 라벨은 이모지만 (선 아이콘 제거)

사용자 요청: "아이콘은 제거해줘 이모지만 있는게 심플하고 일관성있어보여"

## 정한 것

- 화면 어디서나 라벨 선 아이콘을 그리지 않는다. 이모지가 있으면 이모지, 없으면 아무 표시 없이 이름만 보인다.
- 이모지가 없는 라벨은 비워 둔다(사용자 선택). 자동으로 저장하지 않는다. 채우고 싶으면 라벨 관리의 `이름으로 이모지 정하기`(미리보기·되돌리기)를 쓴다.
- 라벨 편집에서 `아이콘` 고르기(`IconPicker`)를 없앤다. `이모지 없음`은 "표시 없음"이 된다.
- 플래너의 숙소·차·도보 같은 라벨이 아닌 아이콘은 그대로다.

## 저장 형식은 그대로

`tripmap:library:v2` schemaVersion 2에서 `icon`은 필수 칸이다. 옛 버전(v0.14.8 이하)이 새 문서를 읽으려면 남아 있어야 하므로
`LABEL_ICONS`·`LabelIcon`·`LabelSchema.icon`, 병합·백업·공유 파일의 `icon` 처리는 바꾸지 않는다.
기존 값은 보존하고 새 라벨은 계속 `'star'`를 쓴다. 화면과 편집에서만 뺀다.
옛 버전으로 되돌리면 아이콘 고르기와 아이콘 표시가 다시 보이고, 저장된 아이콘 값도 그대로 남아 있다.

## 코드 정리

- `src/sections/labels/IconPicker.tsx`(`ICON_NAMES` 포함)와 `setLabelIcon`, 그 시험을 지운다.
- `LabelGlyph`의 `name`(선 아이콘) 대체를 없앤 라벨 이모지 표시로 바꾼다. 이모지가 없으면 `null`을 그린다.
- `LABEL_GLYPHS`에서 라벨 전용으로만 쓰던 선 아이콘 import를 지운다. 플래너가 쓰는 숙소·차·도보 아이콘은 이름 있는 아이콘으로 남긴다.

## 이모지가 없을 때 자리

- 칩·배지·타일처럼 글 안에 들어가는 곳은 자리를 비우지 않고 이름만 보인다(빈 칸·간격 없음).
- 세로로 줄이 맞아야 하는 목록(라벨 관리 줄, 라벨 찾기·고르기·병합 목록 등)은 정렬이 깨지지 않게 같은 너비의 빈 자리를 남겨도 된다.
  라벨 관리 줄의 색 네모는 이모지가 없으면 빈 색 네모로 남는다.
