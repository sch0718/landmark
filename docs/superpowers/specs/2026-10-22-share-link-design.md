# 링크로 공유하고 도메인에서 바로 보기

## 흐름과 링크

장소 내보내기와 일정 공유 창에 `링크 복사`와 `링크 공유`를 더한다. 공유 문서(v1·v2)를 JSON → deflate-raw → base64url로 만들어 `https://landmark.sch0718.dev/view#d=<값>`에 담는다. 서버에는 저장하지 않는다. 앱 주소는 기존 `appUrl(VITE_APP_URL)` 규칙을 따르고 개발·E2E에서는 명시한 주소 또는 현재 출처를 쓴다. 파일 저장과 파일 공유는 기존 문서와 동작을 유지한다.

받는 사람은 `/view`에서 목록·지도·일정을 본다. `Landmark에 담기`는 해시 값을 그대로 둔 `/import#d=<같은 값>`으로 같은 탭에서 이동한다. 파일 보기 화면은 기존처럼 새 탭으로 가져오기를 연다. 같은 탭에 다른 `/view` 해시를 붙여 넣으면 문서를 다시 읽어 화면과 지도 연결을 바꾼다. 제목은 공유 문서 제목이며 정적 설명은 `랜드마크로 공유한 장소`다. 메신저 미리보기는 해시를 읽지 못하므로 항상 같은 설명이다.

## 한도와 안내

해시 값은 최대 32,000자, 풀린 데이터는 최대 5,242,880바이트, 장소는 1~1,000곳이다. 보기 화면에서 Effect 없이 압축을 풀고 앱과 같은 형식·관계·중복 id 검사를 한다. v2는 경로선까지 먼저 담고, 해시 한도를 넘으면 경로선을 모두 비운 사본으로 재시도한다. 풀린 크기나 장소 수도 한도를 넘으면 링크를 만들지 않는다. 링크를 담을 수 없으면 버튼을 끄고 `링크가 너무 길어요. 파일로 보내 주세요`를 표시한다. 압축 기능이 없으면 링크 버튼을 숨긴다.

메모 포함 기본값은 유지한다. 켜져 있으면 링크 버튼 근처에 `링크를 받은 사람은 누구나 메모를 볼 수 있어요`를 표시한다. 복사 성공은 토스트, 복사·공유 실패는 창 안 상태 문구로 알린다. 링크는 창이 열리거나 제목·선택·메모가 바뀔 때 미리 만들어 Web Share API의 사용자 동작 조건을 지킨다. 이전 비동기 결과는 무시한다.

해시가 없거나 손상·과대·잘못된 형식이면 `링크가 손상됐거나 너무 길어요. 보낸 사람에게 파일로 보내 달라고 해 주세요`와 앱 `/`을 여는 `Landmark 열기`를 표시한다.

## 빌드와 배포

기존 단일 파일 보기 화면 빌드가 `public/share-viewer.html`과 데이터 블록이 빈 `public/view.html`을 함께 만든다. 두 결과는 gitignore한다. 설치된 Wrangler의 Pages 정적 자산 처리 코드(`wrangler-dist/cli.js`의 `generateHandler`)가 `${pathname}.html`을 SPA `notFound()`보다 먼저 찾는 것을 확인했다. Cloudflare Pages의 HTML 확장자 없는 정적 경로 처리로 `/view`가 `view.html`을 제공하며 SPA 폴백보다 먼저 선택된다. 기존 `/api/*` Functions와 SPA 설정은 유지한다. Vite 개발 서버에서는 `/view`를 `/view.html`로 내부 재작성한다. 보기 화면 틀은 51,200바이트, 앱 첫 JS gzip은 327,680바이트 이내여야 한다.

옛 버전으로 되돌리면 `/view` 링크가 열리지 않는다. 이미 보낸 HTML 파일은 계속 자체 보기 화면으로 열리며 보관함 저장 형식에는 영향이 없다.

## 시험 계획

- 단위: 링크 길이 경계, 압축 기능 없음, v2 경로선 유지·제거·초과, 한글·이모지·`<` 왕복, 해시·풀린 크기·문서 형식 검사, 오류 화면, 같은 탭 가져오기와 파일 새 탭 유지.
- 공유 창: 복사 성공·실패, 링크 공유 API 유무, 메모 안내, 너무 큰 링크 안내, 변경·닫기 뒤 늦게 끝난 작업 무효화.
- E2E: 장소 내보내기 → 링크 복사 → `/view` 목록·지도 → 같은 탭 가져오기 미리보기 → 가져오기, 일정 링크도 확인한다. Chromium은 클립보드 권한을 주고 실제 값을 읽으며 WebKit은 버튼 상태를 확인한다.
- `yarn lint`, `yarn build:ci`, 지정된 공유 E2E와 새 링크 E2E를 실행한다. 앱은 5179, 시험 지도는 5180을 써서 금지된 5173·5174를 건드리지 않는다. 새 의존성·네트워크·git 변경 명령은 사용하지 않는다.
