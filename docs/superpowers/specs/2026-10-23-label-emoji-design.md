# 라벨 이모지 설계 (개선 묶음 B)

## 저장과 호환

기존 아이콘·색을 유지하고 라벨에 `emoji?: { value: string | null, updatedAt: ISO 시각 }`를 더한다.
`Schema.optional(FieldSchema(Schema.NullOr(LabelEmoji)))`로 검증하며 schemaVersion은 2다.
문자열은 1~16 UTF-16 단위, `Intl.Segmenter('ko', { granularity: 'grapheme' })` 기준 그래핌 하나,
`\p{Extended_Pictographic}` 포함이어야 한다. 변형 선택자·피부색·ZWJ 시퀀스를 허용한다.
여러 이모지·공백·일반 문자열·숫자·국기/키캡(Extended_Pictographic 없음)은 거부한다.
필드 없음과 null 모두 아이콘을 보이되, 지우기는 null과 새 시각을 써서 필드 단위 LWW로 전달한다.
없던 필드에 빈 값을 쓰면 기존 선택 필드 관례대로 키를 만들지 않는다.

옛 문서는 그대로 읽힌다. v0.14.6 이하도 새 문서를 읽지만 모르는 emoji를 떼어 내므로
그 버전에서 무엇이든 저장하면 이모지가 지워진다. 롤백 전 전체 백업을 받고 복귀 후 복원한다.
백업·복원은 보관함 전체를 보관하므로 이모지도 유지한다.

## 표시와 고르기

LabelGlyph에 선택 emoji 인자를 더해 이모지 > 아이콘 순서로 그린다.
칩·배지·관리 목록·타일/bento·라벨 고르기·찾기·병합·일괄 편집·폴더·플래너의 라벨 배지에 적용한다.
아이콘 견본과 교통/숙소처럼 라벨이 아닌 아이콘은 그대로다.
시스템 글꼴의 span으로 이모지를 그리고 장식에는 aria-hidden을 붙여 라벨 이름만 읽힌다.
지도는 첫 번째 살아 있는 라벨의 이모지를 장소 이름 앞에 공백과 함께 붙인다.
계획·당일 지도도 번호 또는 출발지/숙소 표시 다음, 장소 이름 앞에 같은 이모지를 붙인다. 다른 Day의 이름 없는 점은 그대로다.
첫 라벨에 이모지가 없으면 뒤 라벨에서 찾지 않는다. 방문 체크는 기존대로 이모지 앞에 붙는다.
React 텍스트와 지도 textContent만 쓰고 innerHTML은 쓰지 않는다.

라벨 편집에 ‘이모지’ radiogroup을 더한다. 아래 38개와 ‘이모지 없음’을 고를 수 있다.
각 항목은 한국어 접근 이름·44px 이상 목표를 갖는다. Tab은 선택 항목으로 진입하고
화살표/Home/End로 이동·선택, Space/Enter/클릭으로 선택한다.
선택은 즉시 저장한다. ‘이모지 없음’은 기존 아이콘으로 돌아간다. 아이콘 선택은 이모지를 지우지 않는다.
목록 밖의 유효한 이모지도 저장·표시하며 편집기에서 현재 선택으로 제시한다.

## 추천 표 전체

이름을 NFC 정규화하고 아래 순서로 부분 문자열을 검사한다. 먼저 맞는 행이 이긴다.
카페&베이커리는 ☕, 동해안 뷰 맛집은 🌊, 셰프 식당은 👨‍🍳로 고정한다.
‘회’ 한 글자는 ‘회의’ 같은 오탐을 피하려고 단독 단어 또는 횟집/숙성회/생선회/회집/회맛집에만 맞춘다.
단독 회의 경계에서는 Unicode 문자·숫자·결합 문자·밑줄을 제외하여 ‘100회 방문’·‘cafe회’는 추천하지 않는다.
낱말이 없으면 null이다. 이름 끝의 별 이모지 등은 추천의 근거로 쓰지 않는다.

기존 ‘센픽’, ‘군산 아영이랑’에는 추천하지 않는다.

## 기존 라벨 한꺼번에 정하기

관리 화면 위 ‘이름으로 이모지 정하기’ → 미리보기 창 → 체크한 라벨에 ‘적용’.
살아 있고 이모지가 없으며 추천이 있는 라벨만 표시하고 처음에는 전부 체크한다.
각 행은 이름·추천 이모지·한국어 설명·체크박스를 갖는다. 대상 없음 안내와 취소도 제공한다.
적용 때 저장소 최신본을 다시 확인하여 이름/이모지 필드가 미리보기 이후 바뀌거나 삭제된 라벨은 건너뛴다.
저장 실패 시 창을 유지하고, 성공하면 실제 적용 개수와 토스트 ‘되돌리기’를 8초 제공한다.

연산 내부에서 실제 변경 전후의 emoji 필드를 기록한다. 되돌리기는 기록한 이후 값과
updatedAt이 모두 같은 필드만 이전 값으로 새 시각에 쓴다. 원래 키가 없었다면 null 묘비로 복원한다.
다른 탭이 변경한 필드·삭제된 라벨은 덮어쓰지 않고 건너뛴 안내를 표시한다.
색·이름 등 다른 필드는 유지한다.

## 공유·다른 연산·첫 로딩

tripmap-share v1/v2와 파일·링크 규약에는 이모지를 추가하지 않는다.
공유 라벨을 가져와 새로 만들면 이름으로 새 추천을 받는다.
병합은 남는 라벨 이모지를 유지한다. 복제·정렬·기타 연산은 객체 펼치기 관례로 필드를 보존한다.
새 의존성·외부 요청·이모지 이미지/글꼴을 추가하지 않는다.

추천 표·선택기·일괄 창은 라벨 관리 및 기존 lazy 추가/가져오기 경로에서 받는다.
장소 상세의 라벨 생성은 호출 시 생성 모듈을 import해 추천 표가 첫 화면에 들어오지 않게 한다.
일괄 창은 이미 lazy인 LabelsPage 안에 두어 별도 첫 로딩 의존성을 만들지 않는다.
첫 로딩 gzip 예산 327,680바이트를 build:ci로 확인한다.

## 시험과 완료 기준

- 스키마: 없음/null/기본·변형 선택자·피부색·ZWJ 허용, 잘못된 값·여러 그래핌·초과 길이 거부,
  옛 문서 그대로 읽기 및 옛 스키마의 필드 제거.
- 추천: 제공한 사용자 라벨 22개 전부와 전체 추천 표·우선순위·회 오탐을 표 기반 시험.
- 연산: createLabel 첫 값, 가져오기 경로, 정렬·병합 유지, 일괄 적용·원래 빈 값 되돌리기·동시 수정 보호.
- UI: 이모지 우선/아이콘 복귀, 편집기 선택/지우기/키보드/접근 이름, 미리보기 제외·체크·적용·토스트 되돌리기.
- 지도: 첫 라벨만 표시, 삭제 라벨 건너뛰기, 방문 체크·HTML 문자 안전 처리.
- 공유 v1/v2에는 emoji 없음, 백업·복원 유지.
- E2E: 첫 시험 @smoke, 편집→칩/지도, 여러 라벨 추천 적용. desktop/iphone/galaxy에 등록.
- yarn lint, yarn build:ci, U+2028/U+2029 없음 검사. tsx IPC 제한은 같은 단계를 나눠 실행한다.
  공용 E2E 포트/설정은 바꾸지 않는다. 5173/5174를 사용할 수 없어 E2E 실행은 사람에게 맡긴다.
