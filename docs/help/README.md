# 랜드마크 도움말

메뉴마다 실제 화면 흐름을 움직이는 그림으로 보여 줍니다. 서비스 소개는 [README](../../README.md)에 있습니다.

| 메뉴 | 이렇게 써요 |
| --- | --- |
| [보관함](library.md) | 라벨로 거르기 → 지역·이름으로 좁히기 → 길게 눌러 여러 곳 고르기 → 여행에 넣기 |
| [지도](map.md) | 라벨 색 마커로 보기 → 마커 누르기 → 내 위치 보기 → 가까운 곳만 보기 |
| [장소 추가](add.md) | ＋ 누르기 → 링크 붙여넣기 → 확인하고 추가 → 네이버 폴더 통째로 |
| [장소 상세](place.md) | 장소 열기 → 라벨 바꾸기 → 다녀옴·한 줄 평 → 메모는 저절로 저장 |
| [라벨 관리](labels.md) | 라벨 목록 → 색·이모지 고치기 → 이름으로 이모지 정하기 → 네이버 폴더 다시 가져오기 |
| [여행](trips.md) | 새 여행 만들기 → 후보 담고 Day에 넣기 → Day 일정과 이동 시간 → 여행 당일 모드 |
| [약속](meetings.md) | 새 약속 → 참석자 출발지 → 중간 지점 찾기 → 링크로 함께 고르기 |
| [공유](share.md) | 내보내기 열기 → `링크 복사` → 받은 사람이 열기 → 내 보관함에 담기 |
| [설정](settings.md) | 테마와 모드 → 백업 파일 받기 → 다른 기기에서 되살리기 → 백업 알림 |

그림은 `yarn build:motion`이 `scripts/motion/help-pages.mjs`로 만듭니다. 화면 문구가 바뀌면 그 파일을 고치고 다시 만드세요.
